# 🌙 Pip's Midnight Nursery | Baby's First Portfolio
> **Track 1 Entry** for the [haX.baby](https://hax.baby) *"Baby's First Website"* 48-Hour Hackathon (17–19 October 2026).

![Track 1: Pip, The Skull Baby](https://hax.baby/baby/assets/pip_avatar_cloud.png)

Welcome to the official portfolio and digital home of **Pip, The Skull Baby** — Junior Dream Engineer at Midnight Nursery! 

Pip designs gentle lullabies, warm bedside nightlights, and starry delivery flight routes that help little creatures everywhere fall asleep safely.

---

## ✨ Features & Hackathon Requirements Met

### 1. Character Identity & Visual Style ("What They Are")
- **Custom Aesthetic**: Designed using haX.baby's signature editorial palette — Warm Cream (`#fff8f1`), Deep Berry (`#a34063`), Cozy Brown (`#5c4033`), and Starlight Gold.
- **Interactive Eye-Tracking Pip Avatar**: Vector-rendered Pip whose glowing amber pupils track the visitor's cursor across the screen in real-time.
- **Day / Night "Dream Mode" Switcher**: Smooth color-shifting background transition between cozy daytime nursery and deep indigo night sky.

### 2. Showcase Projects ("What They Do" - 3 Multi-Page Apps)
Pip's creations are featured across 3 dedicated, interactive sub-pages:
1. 🎵 **[The Lullaby Lab (`lullaby-lab.html`)](./lullaby-lab.html)**: An interactive 4-note pentatonic Web Audio synth matrix featuring visual ripple animations and note sequence logging.
2. 🏮 **[Dream Lantern Collection (`dream-lanterns.html`)](./dream-lanterns.html)**: Interactive bedside light box that casts custom ambient color glows (Amber, Berry Rose, Starlight Teal) across the room.
3. 🧱 **[Rattle & Stacking Blocks (`rattle-blocks.html`)](./rattle-blocks.html)**: A playable wooden block stacking toy box with drop physics animations and acoustic wood rattle sound effects.

### 3. Bedtime Story Scroll ("Their Story")
- A cozy, progressive 2-scene bedtime journey telling Pip's waking hour routine and dream delivery preparation (<150 words per scene).

### 4. Interactive Ledger & Post-Signing Explorer Guide
- **Welcoming Nursery Visitor Ledger**: An interactive guestbook with custom avatar selection (`⭐ Star Catcher`, `🌙 Night Owl`, etc.) and real-time ledger signing.
- **Bedtime Explorer Guide**: Signing the ledger triggers a celebration confetti explosion and unlocks an interactive modal revealing Pip's hidden secret tips and keyboard shortcuts!

## 🌟 Side Quests & Bonus Points Completed (+13 pts)

- **+3 pts — Web Audio Chimes & Mute Switch**: Zero-dependency Web Audio API synthesizer for all button clicks and chimes with an accessible top-bar Mute toggle (`🔊` / `🔇`).
- **+2 pts — Stardust Sparkle Cursor Trail**: Retro twinkling stardust particles that follow mouse movement.
- **+2 pts — Live Visitor Ledger**: Real-time persisted nursery guestbook wall with custom badges.
- **+1 pt — "Dreams Delivered" Odometer**: Vintage hit-counter ticker tracking total dreams delivered.
- **+5 pts — Responsive Chaos & Easter Egg**: Click Pip 5 times rapidly to trigger a 360° spin and a stardust confetti cannon explosion (`canvas-confetti`).
